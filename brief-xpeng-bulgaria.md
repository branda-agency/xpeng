# XPENG Bulgaria — Official Website for Market Entry

## Project Name
XPENG Bulgaria Website

## Project Description
Full website build for XPENG's exclusive Bulgarian distributor BAI (Bulgarian Automotive Industry EAD). XPENG is a Chinese electric vehicle manufacturer that sold 400,000+ cars globally last year. BAI becomes the exclusive XPENG distributor in Bulgaria from September 2026. The website must be live by June 10, 2026 for a major launch event in Riga (June 18) where journalists and PR will be directed to the site.

This is a two-phase project:
- **Phase 1 (deadline June 10, 2026):** Functional multipage website with landing page, 3 product pages, test drive booking, and legal compliance pages.
- **Phase 2 (deadline end of July 2026):** Immersive award-winning redesign with video/photo content from Riga event, configurator, expanded pages (About, News, Services, Support, Find Us).

## Website Type
Multipage website for Phase 1 (landing + product pages + utility pages). Immersive/creative for Phase 2.

## Platform & Tech Stack
- **CMS/Builder:** Webflow (visual builder, Webflow-hosted)
- **Custom code:** GSAP animations (ScrollTrigger, SplitText, CustomEase) + Lenis smooth scroll, bundled via Vite, hosted on Cloudflare Pages
- **Domain:** xpeng.com/bg (subdirectory under XPENG HQ domain — they manage DNS, we provide the site via Webflow with reverse proxy)
- **Analytics:** Google Tag Manager + Google Analytics
- **Forms:** Webflow native forms for Phase 1 (submissions stay in Webflow dashboard)
- **Existing lead capture:** Simple landing page on Vercel with Supabase backend (will be replaced by Webflow site)

Medium-high (4 out of 5). Reasons:
- Custom GSAP scroll-triggered animations (text reveals, element reveals, parallax)
- Lenis smooth scroll integration
- Responsive design with mobile-first approach
- Cookie consent integration (OneTrust or Cookiebot)
- Custom form validation (consent checkbox must block submission)
- SEO requirements (structured data, sitemaps, meta optimization)
- Brand compliance with XPENG HQ guidelines (specific fonts, logos, image specs)
- Multilingual considerations (Bulgarian with Cyrillic — font compatibility concerns with Basis Grotesque Pro)

## Content Strategy

### Per Product Page — Priority Order:
1. **Price** — prominently displayed at top
2. **Smart Mobility / App integration** — key differentiator, NOT buried at bottom. "If our car is smart but we don't show it, there's no difference from a 2017 car"
3. **Warranty & credibility indicators** — Euro NCAP certifications, Red Dot Design Award (P7 Plus)
4. **Interior quality** — leather, alcantara, premium workmanship. Must be communicated in all marketing.
5. **Key specs** — range, acceleration, battery type (LFP), 800V platform

### What NOT to Communicate:
- 12-minute charging claim (requires 800V stations which Bulgaria lacks; realistic is ~20 minutes on available infrastructure)
- Dense service network (doesn't exist yet at launch, still being built)

### Visual Assets:
- Sourced from existing XPENG global/regional websites (photos, videos)
- No custom photography for Phase 1
- Phase 2 will include footage from Riga event (~3 days shooting around June 15 with cars, humanoid robot, flying car)

### Language:
- Bulgarian only for Phase 1
- Possible English version in Phase 2 (TBD)

## Brand Guidelines & HQ Requirements
XPENG HQ (China) has strict brand guidelines that must be followed:

### Typography:
- **Body text:** System font stack (-apple-system, BlinkMacSystemFont, Segoe UI, Roboto, sans-serif)
- **Headings/Titles:** Basis Grotesque Pro (commercial font by Colophon Foundry). **IMPORTANT:** Only the PRO version supports Cyrillic. Standard version is Latin-only. If HQ doesn't provide Pro license, fallback to Inter (Google Fonts, free, excellent Cyrillic).
- Line height rule: N+12

### Branding:
- Always use official electronic logo files (never redraw)
- Brand name always spelled "XPENG" in uppercase
- Brand positioning: "XPENG BG" (not "XPENG Auto")

### HQ Approval Process (RISK):
- Must submit staging link + signed domain authorization documents
- HQ does 2 rounds of Content/Structure/Visual review (5-7 working days each)
- Then Security & Legal Review
- Then Domain configuration & official go-live
- Normal process takes MONTHS — we're trying to expedite
- Strategy: show concept to BAI by May 15, they present to Chinese side early for validation
